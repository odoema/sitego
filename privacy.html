Privacy Policy

Last updated: October 25, 2026

SiteGo is a local-first publishing tool by Brian Odoch Emmanuel. SiteGo is designed to inspect and publish files from a local website or web-app project.

Information handled

  • SiteGo reads local repository files and Git metadata needed to perform the actions you request.
  • SiteGo may scan selected files for common secret patterns before publishing.
  • When you publish, the selected files are committed and pushed to the GitHub repository you configured. GitHub then processes and stores that repository data under GitHub's own policies.
  • SiteGo's verification step may request the public deployment URL you specify to confirm that it responds.

Local-first design

SiteGo does not require a SiteGo-operated cloud database for its core publishing workflow. Credentials and secrets should never be placed in the plugin package or committed to repositories.

Third-party services

GitHub, GitHub Actions, GitHub Pages, and any other hosting or deployment service you choose may collect and process information according to their own privacy policies. SiteGo does not control those services.

Contact

For privacy questions, open an issue in the SiteGo GitHub repository.
