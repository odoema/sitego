# Third-party notices

SiteGo currently uses Electron as a development dependency. Electron, Chromium, Node.js, and any platform-specific binary packages retain their respective copyrights and license terms. Before distributing a built installer, generate and ship the complete notices required by the exact dependency lockfile and bundled binaries.

No fonts, icons, stock images, or copied website templates are bundled with this initial source version. The interface uses system fonts with an optional Google Fonts stylesheet; remove that remote font import or bundle a properly licensed font before a privacy-sensitive or fully offline release.
